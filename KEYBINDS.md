# Keybind map

Custom binds from `hypr/custom/keybinds.lua` (override Illogical Impulse defaults).

## Shell / Quickshell

| Key | Action |
|-----|--------|
| `Super+Z` | Launcher / search |
| `Super+D` | Overlay widgets (dashboard) |
| `Super+Shift+D` | Left sidebar (assistant) |
| `Super+R` | Right sidebar (quick toggles) |
| `Super+T` | Tmux in kitty |
| `Super+B` | Wallpaper selector |
| `Super+Esc` | Power / session menu |
| `Super+Shift+C` | II settings panel |
| `Super+E` | Cheatsheet |
| `Shift+Ctrl+S` | Region screenshot |
| `Super+Alt+B` | Reload quickshell |
| `Super+Ctrl+Alt+B` | Quit quickshell |

## Apps

| Key | Action |
|-----|--------|
| `Super+X` | Terminal (`variables.lua`) |
| `Super+F` | File manager |
| `Super+C` | Browser |
| `Super+N` | Cava |

## Windows / workspaces

| Key | Action |
|-----|--------|
| `Super+H` | Fullscreen |
| `Super+W` | Float / tile |
| `Super+Q` | Close (II default) |
| `Super+Shift+Q` | Exit Hyprland |
| `Super+S` | Toggle scratchpad |
| `Super+Shift+S` | Move window to scratchpad (follow) |
| `Super+1..0` | Focus workspace (II default) |
| `Super+Shift+1..0` | Move window to workspace (follow) |
| `Super+arrows` | Focus window |
| `Super+Shift+arrows` | Move window |
| `Super+Alt+arrows` | Resize window |
| `Super+Shift+Z` / `X` | Previous / next workspace |
| `Super+Shift+Tab` | Previous workspace (history) |
| `Super+L` | Lock (II default) |

## Disabled II defaults

- Super alone (search-on-release / workspace number jump)
